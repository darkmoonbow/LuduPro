# Privacy Policy

**Effective Date:** May 6, 2026

This Privacy Policy describes how the browser extension (“the Extension”) collects, uses, and stores data.

---

## 1. Data Collection

The Extension collects and processes the following data:

- A client-generated UUID
- A public user identifier associated with the Luduvo forum
- User-submitted media URLs provided through the Extension

No additional personally identifiable information such as name, email address, or physical address is collected.

---

## 2. Purpose of Data Use

The collected data is used for the following purposes:

- Providing global profile customization features
- Synchronizing user interface themes via a remote database
- Displaying enhanced forum-related information such as post count and reputation
- Enabling user-submitted media display within profiles

---

## 3. Data Storage and Processing

Data is stored and processed using a Supabase backend:

https://rtdifkkdloqfiazlndez.supabase.co

This backend is used to store and retrieve user configuration data and profile-related settings. Data is transmitted between the Extension and this backend to support synchronization of user preferences.

---

## 4. Network Access and Permissions

### https://forum.luduvo.com/*

This permission is used to enhance the Luduvo forum experience by displaying additional profile information such as post count and reputation. The Extension injects interface elements into forum profile pages and reads publicly available page content solely for display purposes.

No data is collected from unrelated websites or non-forum pages.

### https://rtdifkkdloqfiazlndez.supabase.co/*

This permission is used to communicate with a Supabase backend for storing and retrieving user-specific configuration data, including themes and profile metadata.

---

## 5. Data Sharing

The Extension does not sell, rent, or share collected data with third parties.

Data is only transmitted between the client and the Supabase backend described above.

---

## 6. Data Retention

Stored data remains in the database until it is deleted by the user or removed by administrative action.

Users may request deletion of their data by contacting the developer.

---

## 7. Security

Reasonable measures are taken to protect stored data from unauthorized access, alteration, or disclosure. However, no method of transmission or storage is fully secure.

This Privacy Policy may be updated at any time. Continued use of the Extension after changes are posted constitutes acceptance of the updated policy.
